# Rate Easy

A simple, mobile-friendly page for sharing your experience and leaving a rating.

## Live site

👉 **[https://rate-easy.netlify.app](https://rate-easy.netlify.app)**

Open the link above in any browser — no installation needed.

## About

The whole site is a single static `index.html` file, hosted on Netlify. Changes pushed to the `main` branch are deployed to the live site automatically.
